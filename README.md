# 📖 Álbum Digital Imersivo - "Amor"

Este projeto é um álbum de fotos digital de alta fidelidade, construído com uma estética **Skeuomórfica**. O objetivo é recriar a sensação física e tátil de um álbum de memórias real dentro do navegador, utilizando as tecnologias mais modernas de desenvolvimento web.

## ✨ Principais Funcionalidades

- **Física de Livro Real:** As páginas viram com profundidade 3D, sombras dinâmicas e iluminação que reage ao movimento, criando uma experiência quase palpável.
- **Estética Skeuomórfica:** Design premium com texturas de couro na capa, papel texturizado nas páginas e detalhes em dourado, simulando um objeto físico de luxo.
- **Otimização para Celular:** O álbum detecta o dispositivo e ajusta automaticamente sua altura e largura para preencher a tela, garantindo imersão total em dispositivos móveis.
- **Som e Música:** 
  - Trilha sonora ambiente com controles de volume automáticos.
  - Efeitos sonoros de "papel virando" gerados em tempo real via código para cada interação.
- **Integração de Vídeos:** Suporte para vídeos que se integram perfeitamente às fotos e começam a tocar de forma inteligente conforme você folheia o álbum.
- **Sistema de Pré-carregamento:** Uma barra de progresso elegante na capa garante que todas as fotos e vídeos sejam baixados antes do álbum abrir, evitando travamentos ou fotos em branco.
- **Navegação Intuitiva:** Suporte para gestos de deslizar (swipe) no celular, cliques laterais e setas do teclado no computador.

## 🛠️ Tecnologias de Ponta

- **HTML5 & CSS3:** Uso intensivo de Flexbox, Grid e transformações 3D complexas.
- **JavaScript Puro (Vanilla JS):** Lógica personalizada para cálculos de geometria, estados do álbum e responsividade em tempo real.
- **Web Audio API:** Tecnologia avançada para sintetizar efeitos sonoros de forma procedural.
- **Modo Tela Cheia (Fullscreen):** API nativa para proporcionar a máxima imersão visual.

## 📂 Como o Projeto está Organizado

- `index.html`: Contém toda a estrutura, os estilos visuais e a lógica de programação.
- `assets/`: Texturas essenciais (couro, papel, ouro).
- `fotos/`: Onde ficam todas as suas memórias em imagem.
- `videos/`: Pasta para os momentos em movimento.
- `musica/`: Contém a trilha sonora do álbum.

## 🚀 Como Iniciar

1. Certifique-se de que as pastas de fotos, vídeos e músicas estão preenchidas.
2. Abra o arquivo `index.html` em qualquer navegador atual.
3. Aguarde o carregamento completo (indicado na capa do álbum).
4. Clique em **"Abrir Álbum"** e aproveite a viagem pelas suas memórias.
